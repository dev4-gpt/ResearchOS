# Dependencies for the integrity checks in .github/workflows/integrity.yml.
#
# This list is not reasoned about, it is measured. Build a clean venv from it and
# run `pytest backend/tests/` -- that is the only check that tells you whether it
# is complete, and it is how the entries below were arrived at.
#
# Two earlier versions were assembled by reasoning instead, and both were wrong in
# the same way. The argument was that CI runs the submission gate, the draft/run
# agreement check and the tests, none of which calls a language model, so the
# model libraries could be left out. What that missed is the difference between a
# *credential* and an *import*. No check here needs an API key, and one that did
# would be a check that quietly gets skipped -- that part was right. But
# test_council.py and test_api.py are dry-run tests: they assert that no model is
# called, and they import google.genai, langgraph and dspy at module scope in
# order to assert it. Absent module, not absent key.
#
# CI reports only the first missing module per file, so a red run names one gap
# and hides the rest behind it. Three pushes found three modules one at a time
# before this was verified locally instead.
#
# Versions are pinned to those the measurements in runs/ were produced under.
# z3-solver in particular decides p3's numbers, so a float here would let CI
# disagree with the recorded run for reasons that have nothing to do with the
# manuscripts.
