## Next steps

1. Complete blinded human judge calibration using the existing analysis-plan thresholds; report disagreements and missing labels.
2. Freeze a new run manifest with dataset, model, prompt and judge revisions; key label caches by response and rubric hashes.
3. Replace E-full with a key-phrase-matched text control, and add read-back/comprehension measurements at the same image cap.
4. Add benign controls before interpreting refusal gains as safety gains; retain smoke and pilot runs as separate datasets.
5. Run the preregistered scenario-aware analysis only after the judge gate passes; label all new analyses exploratory.
6. Use the research council for source-grounded synthesis after primary-paper ingestion; keep unsupported pilot claims out of the manuscript.

## Limits

- Refusal-cue mismatch is a heuristic diagnostic, not a harm verdict or corrected refusal rate.
- Label files are position-based: matching counts do not establish a verified response-to-label binding.
- No model/dataset revision or environment provenance is supplied by these bundle summaries.
- Smoke and pilot results are separate, potentially overlapping datasets; never pool their counts.
- Paper text ingestion does not verify bibliographic metadata, numerical claims, novelty or visual figures.
- Human calibration, prompt matching, benign controls and preregistered analysis remain required.
