# Self-Consistency Improves Chain of Thought Reasoning in Language Models

## 1. Executive Summary
This paper introduces **Self-Consistency**, a novel decoding strategy that replaces the traditional greedy decoding used in [[Chain-of-Thought Prompting]] (CoT). The core intuition is that complex reasoning tasks typically have multiple valid pathways leading to the correct answer. By sampling a diverse set of reasoning paths from a Large Language Model (LLM) and selecting the most consistent final answer (i.e., a majority vote), self-consistency significantly boosts performance on arithmetic, symbolic, and commonsense reasoning benchmarks without requiring additional training or fine-tuning.

---

## 2. Exact Claims & Hypotheses
*   **Hypothesis 1 (Diverse Reasoning Paths):** For complex reasoning tasks, there exist multiple distinct thought processes (paths) that arrive at the same correct final answer.
*   **Hypothesis 2 (Consistency Correlates with Accuracy):** If multiple sampled reasoning paths lead to the same output answer, there is a higher probability that this consensus answer is correct compared to an answer generated from a single greedy decoding path.
*   **Core Claim:** Integrating a majority-vote mechanism over sampled reasoning paths (Self-Consistency) yields a robust accuracy improvement over standard [[Chain-of-Thought Prompting]] across diverse LLM architectures (e.g., PaLM, GPT-3, Codex).

---

## 3. Methodology & Algorithm

```
                  +---> Sample Path 1 ---> Answer A
                  |
[Input Prompt] --->+---> Sample Path 2 ---> Answer B ---> [Majority Vote] ---> Final Answer A
                  |
                  +---> Sample Path N ---> Answer A
```

Instead of greedily generating a single reasoning path, the self-consistency method operates as follows:

1.  **Prompting:** Prompt the LLM using standard [[Chain-of-Thought Prompting]] templates (e.g., few-shot exemplars with manual reasoning steps).
2.  **Sampling (Generation):** Sample a diverse set of $N$ independent reasoning paths $\{r_1, r_2, \dots, r_N\}$ from the model's decoder. 
    *   This is achieved using sampling strategies such as **Temperature Sampling** (e.g., $T = 0.7$) or **Top-$k$ / Nucleus (Top-$p$) Sampling** rather than greedy decoding ($T=0$).
3.  **Marginalization & Voting:** Extract the final answer $a_i$ from each reasoning path $r_i$. The optimal answer $a^*$ is selected by taking the majority vote (marginalizing out the reasoning paths):

$$a^* = \arg\max_a \sum_{i=1}^{N} \mathbb{I}(\text{extract}(r_i) = a)$$

*Where:*
*   $r_i$ is the generated chain of thought containing both the reasoning and the candidate answer.
*   $\text{extract}(r_i)$ is a parser function mapping the reasoning path to its final concrete answer.
*   $\mathbb{I}$ is the indicator function.

## 4. Experimental Setup & Datasets
The authors evaluated the methodology across three primary reasoning domains using models such as PaLM (62B, 540B), LaMDA (137B), GPT-3 (175B), and Codex.

### Datasets Evaluated
*   **Arithmetic Reasoning:**
    *   **GSM8K** (Grade school math word problems)
    *   **SVAMP** (Synthesis of math word problems with variations)
    *   **MultiArith** (Multi-step arithmetic)
    *   **ASDiv** (Diverse math word problems)
    *   **AQUA-Rat** (Algebra word problems with multiple-choice options)
*   **Commonsense Reasoning:**
    *   **StrategyQA** (Multi-step implicit commonsense reasoning)
    *   **ARC-Challenge** (Science exam questions)
*   **Symbolic Reasoning:**
    *   **Last Letter Concatenation** (e.g., "take the last letters of 'Elon Musk' -> 'nk'")
    *   **Coin Flip** (Tracking state changes over a sequence of flips)

## 5. Key Quantitative Results

The application of Self-Consistency yielded dramatic improvements over standard CoT across all benchmarks:

| Dataset | Model | Standard CoT (Greedy) | CoT + Self-Consistency ($N=40$) | Absolute Gain |
| :--- | :--- | :---: | :---: | :---: |
| **GSM8K** | PaLM-540B | 56.5% | **74.4%** | **+17.9%** |
| **SVAMP** | PaLM-540B | 79.0% | **86.6%** | **+7.6%** |
| **MultiArith** | PaLM-540B | 93.3% | **99.3%** | **+6.0%** |
| **AQUA-Rat** | PaLM-540B | 35.8% | **48.3%** | **+12.5%** |
| **StrategyQA** | PaLM-540B | 72.1% | **81.6%** | **+9.5%** |

### Additional Insights
*   **Sample Size Scaling ($N$):** Performance scales logarithmically with the number of sampled paths. Sampling $N=40$ paths captures the majority of gains, though sampling up to $N=256$ continues to show minor improvements.
*   **Robustness:** Self-consistency is highly robust to variations in prompt formatting, the selection of few-shot exemplars, and changes in the temperature parameter ($T \in [0.5, 1.0]$).

---

## 6. Limitations Acknowledged by the Authors
1.  **Computational Overhead:** Since the method requires sampling $N$ parallel/independent outputs (typically $N \in [10, 40]$) per query, it scales inference-time computational cost, latency, and API usage fees linearly by a factor of $N$.
2.  **Calibration and Answer Aggregation:** For open-ended generative tasks where answers cannot be easily parsed into discrete equivalence classes (e.g., writing essays or code generation without test suites), simple majority voting is difficult to apply directly without embedding similarity clustering.
3.  **Dependence on Baseline Capability:** Self-consistency cannot rescue a model that lacks the foundational capacity to reason. If the model is too small or completely untrained on the task domain, the sampled paths will converge on highly consistent *incorrect* answers.
