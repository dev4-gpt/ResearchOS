1. **Prompting:** Initialize the model using standard [[Chain-of-Thought Prompting]] datasets/prompts.
2. **Diverse Sampling:** Rather than greedy decoding, use a sampling-based decoding strategy (e.g., Temperature Sampling or Nucleus Sampling) to generate a diverse set of $N$ independent reasoning paths:
   $$\{r_1, r_2, \dots, r_N\}$$
3. **Marginalization (Majority Vote):** Extract the final answer $a_i$ from each reasoning path $r_i$, and select the ultimate answer $A^*$ that achieves the highest consensus:
   $$A^* = \arg\max_{a} \sum_{i=1}^{N} \mathbb{I}(a_i = a)$$
   *(where $\mathbb{I}$ is the indicator function).*

## Experimental Benchmarks & Quantitative Results

The self-consistency decoding strategy was evaluated across several prominent arithmetic and commonsense reasoning datasets. It demonstrated a striking performance boost over naive CoT prompting:

| Dataset | Task Domain | Performance Gain (Absolute % Improvement) |
| :--- | :--- | :--- |
| **[[GSM8K]]** | Grade school math word problems | **+17.9%** |
| **[[AQuA]]** | Algebraic word problems with options | **+12.2%** |
| **[[SVAMP]]** | Math word problem variations | **+11.0%** |
| **[[StrategyQA]]** | Multi-step commonsense reasoning | **+6.4%** |
| **[[ARC-Challenge]]** | Grade-school science questions | **+3.9%** |

## Limitations (Acknowledged & Derived)

* **Computational Cost:** *The primary trade-off of self-consistency is inference cost.* Sampling $N$ different reasoning paths requires $N$ times more computational resources and tokens than a single greedy pass.
* **Open-Ended Generation Limitation:** The method relies on the ability to extract a discrete final answer (e.g., a number, a multiple-choice option, or a short span) to perform majority voting. Applying self-consistency to open-ended, subjective generation tasks is more complex and less straightforward.
* **Dependence on Sample Diversity:** If the underlying language model is highly biased or consistently repeats the exact same logical fallacy across all sampled paths, self-consistency may confidently converge on a wrong answer.
