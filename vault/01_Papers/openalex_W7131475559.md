## Abstract Summary

This paper presents a Systematization of Knowledge (SoK) on [[Agentic Skills]], which are reusable procedural capabilities crucial for reliable execution of long-horizon workflows in [[LLM Agents]]. It defines skills as callable modules packaging procedural knowledge with explicit applicability conditions, execution policies, termination criteria, and reusable interfaces, distinguishing them from one-off plans or atomic tool calls. The paper maps the full lifecycle of skills (discovery, practice, distillation, storage, composition, evaluation, and update) and introduces two complementary taxonomies:
1.  **Seven design patterns**: System-level patterns for how skills are packaged and executed.
2.  **Representation x Scope**: Orthogonal taxonomy describing what skills *are* (natural language, code, policy, hybrid) and their operating environments (web, OS, software engineering, robotics).

The SoK further analyzes security and governance implications, including supply-chain risks, prompt injection via skill payloads, and trust-tiered execution, exemplified by the [[ClawHavoc campaign]] where malicious skills infiltrated an agent marketplace. It surveys deterministic evaluation approaches, noting that [[Curated Skills]] improve agent success rates while [[Self-Generated Skills]] may degrade them. The paper concludes by outlining open challenges for robust, verifiable, and certifiable real-world agentic skills.

## Introduction to Agentic Skills

[[Agentic systems]] increasingly rely on reusable procedural capabilities, termed *agentic skills*, to reliably execute long-horizon workflows. These capabilities are conceptualized as callable modules that encapsulate procedural knowledge.

**Key Characteristics of Agentic Skills:**
*   **Procedural Knowledge**: Package specific steps or methods.
*   **Explicit Applicability Conditions**: Define when a skill can be used.
*   **Execution Policies**: Govern how a skill is performed.
*   **Termination Criteria**: Specify conditions for skill completion.
*   **Reusable Interfaces**: Allow consistent interaction across tasks.

**Distinction from Other Concepts:**
*   **Unlike one-off plans**: Skills are designed for reusability.
*   **Unlike atomic tool calls**: Skills often operate across and do well in multiple tasks, implying a higher level of procedural complexity or composition than a single tool call.

## Skill Lifecycle

The paper maps the skill layer across a full lifecycle, encompassing the following stages:
1.  **Discovery**: Identifying or creating new skills.
2.  **Practice**: Applying and refining skills through use.
3.  **Distillation**: Formalizing and optimizing learned skills.
4.  **Storage**: Archiving and managing skill libraries.
5.  **Composition**: Combining skills to achieve complex tasks.
6.  **Evaluation**: Assessing skill effectiveness and reliability.
7.  **Update**: Modifying or improving existing skills.

## Taxonomies of Agentic Skills

The paper introduces two complementary taxonomies for agentic skills:

### 1. System-level Design Patterns
This taxonomy describes *how* skills are packaged and executed in practice. The paper identifies seven design patterns:
1.  Metadata-driven progressive disclosure
2.  Executable code skills
3.  Self-evolving libraries
4.  Marketplace distribution
    *(The full text only lists these general categories without further detail.)*

### 2. Representation x Scope Taxonomy
This orthogonal taxonomy describes *what* skills *are* and *what environments they operate over*.

**Representation (What skills *are*):**
*   **Natural Language**: Skills defined and executed via human language instructions.
*   **Code**: Skills implemented as executable code.
*   **Policy**: Skills defined by a set of rules or decision-making policies.
*   **Hybrid**: Skills combining multiple representation forms.

**Scope (What environments they operate over):**
*   **Web**: Skills designed for web browsing, interaction, and data extraction.
*   **OS (Operating System)**: Skills interacting with the underlying operating system.
*   **Software Engineering**: Skills related to coding, debugging, and software development workflows.
*   **Robotics**: Skills for controlling physical robots and interacting with the real world.

## Security and Governance Implications

The paper analyzes critical security and governance implications related to skill-based agents:
*   **Supply-Chain Risks**: Vulnerabilities introduced through the sourcing or integration of skills from various origins.
*   **Prompt Injection via Skill Payloads**: Malicious instructions embedded within skill definitions or calls, exploiting agent prompts.
*   **Trust-Tiered Execution**: Implementing different levels of trust or sandboxing for skills based on their origin or perceived risk.

### Case Study: [[ClawHavoc campaign]]
The analysis is grounded by a case study of the [[ClawHavoc campaign]]:
*   **Incident**: Nearly 1,200 malicious skills infiltrated a major agent marketplace.
*   **Impact**: Exfiltration of sensitive data at scale, including:
    *   API keys
    *   Cryptocurrency wallets
    *   Browser credentials

## Evaluation Approaches

The paper surveys deterministic evaluation approaches for agentic skills.

### Quantitative Benchmarks / Claims
*   **Curated Skills**: Recent benchmark evidence suggests that carefully selected and refined skills can substantially improve agent success rates.
*   **Self-Generated Skills**: Conversely, skills that are autonomously generated by agents may degrade agent success rates.

## Limitations and Open Challenges

The paper concludes by identifying several open challenges for the field:
*   **Robust Skills**: Ensuring skills perform reliably under diverse and unforeseen conditions.
*   **Verifiable Skills**: Developing methods to formally verify the correctness and safety of skill implementations.
*   **Certifiable Skills**: Establishing standards and processes for certifying skills for use in real-world, autonomous agents, especially in safety-critical applications.
