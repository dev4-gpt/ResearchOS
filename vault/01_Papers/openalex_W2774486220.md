# [[lmerTest Package: Tests in Linear Mixed Effects Models]]

## Overview
This paper describes the [[lmerTest]] R package, which addresses a common user need for obtaining p-values for F and t-tests in objects returned by the `lmer` function of the [[lme4]] package for linear mixed effects models. The package extends the 'lmerMod' class to provide these p-values and introduces several other convenience tools for mixed model analysis.

## Methodologies, Algorithms, and System Architecture

### Core Functionality
*   **Extension of [[lme4]]**: The [[lmerTest]] package extends the `'lmerMod'` class from the [[lme4]] package.
*   **Overloading Functions**: It overloads the `anova` and `summary` functions to provide p-values for tests of fixed effects.

### P-value Approximation Methods Implemented
*   **[[Satterthwaite's method]]**: Implemented for approximating degrees of freedom for t and F tests.
*   **[[Kenward-Roger approximation]]**: Provides an alternative method for calculating denominator degrees of freedom for both `summary` and `anova` tables. This implementation relies on the `KRmodcomp` function from the [[pbkrtest]] package.

### ANOVA Table Construction
*   The package facilitates the construction of [[Type I ANOVA]], [[Type II ANOVA]], and [[Type III ANOVA]] tables.

### Additional Mixed Model Analysis Tools
*   **`step` method**: Performs backward elimination of non-significant effects, applicable to both random and fixed effects.
*   **Population Means**: Calculation of population means.
*   **Multiple Comparison Tests**: Support for multiple comparison tests.
*   **Plot Facilities**: Provision of plotting capabilities.
